# Feedback

You don't need to write a detailed review. A quick "this felt like a real objection" or "the role card gave too much away" helps.

## The Easy Option

[Share feedback in the short form](https://github.com/shaunmarsden/sales-conversation-gym/issues/new?template=feedback.yml).

It asks four things, plus an optional fifth:

1. what you were trying to do;
2. what was useful;
3. where you got stuck;
4. whether the likely result felt worth the effort; and
5. what would make this more useful next time (optional).

## If You Are Not Ready To Try It Yet

You can still say what would make this more useful for your own practice. For example:

> I would use this to practise [type of conversation]. I need a scenario for [situation]. I am unsure whether [thing that puts you off].

That is enough to improve the next version.

## Keep It Safe

Don't put customer, employer, confidential or personal information in a public issue. Describe the kind of situation and where you got stuck instead.

If you're adapting this inside your own organisation, use the feedback route your organisation has approved.
