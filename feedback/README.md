# Feedback

You do not need to write a detailed review. A quick "this felt like a real objection" or "the role card gave too much away" is genuinely useful.

## The Easy Option

[Share feedback in the short form](https://github.com/shaunmarsden/sales-conversation-gym/issues/new?template=feedback.yml).

It asks four things:

1. what you were trying to do;
2. what was useful;
3. where you got stuck; and
4. whether the likely result felt worth the effort.

## If You Are Not Ready To Try It Yet

You can still say what would make this more useful for your own practice. For example:

> I would use this to practise [type of conversation]. I need a scenario for [situation]. I am unsure whether [thing that puts you off].

That is enough to improve the next version.

## Keep It Safe

Do not add customer, employer, confidential or personal information to a public issue. Describe the type of situation and the point where you got stuck instead.

If you are adapting this inside your own organisation, use the feedback route your organisation has approved.
